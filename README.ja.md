# FormFillAI

**Mac のどの入力欄でも、`⌥ Space` を押すと、そこに入れるべき自分の情報が入ります。**
フリガナ、「株式会社は除く」、全角指定、郵便番号 2 ボックス、電話番号 3 ボックス —— 日本のフォーム特有の面倒を前提に作っています。

[English README](README.md)

```
⌥ Space → （小さなスピナー）→ 値が入る → [違う] ボタンだけが 4 秒出る
```

## しくみ

```
登録情報 → 入力候補 → Jev が 1 回だけ選ぶ → ローカルで変換 → 貼り付け
```

値は 1 回登録するだけです（`サンプル商事株式会社`）。フォームが求めそうな表記 —— 法人格なし、全角、分割した各部分 —— は
**候補**として自動で用意されます。ショートカットを押すと、macOS のアクセシビリティ機能でフォーカス中の入力欄
（ラベル、プレースホルダ、周辺の文字、並んだボックスの何番目か）を読み取り、小さな判断モデル
[Jev](https://vercel.com/ai-gateway/models/jev) に **「この欄にはどの候補を入れるべきか」を 1 回だけ**聞きます。

モデルは文字列を生成も加工もしません。変換はすべてローカルの決定論的なコードです。

| 登録する値 | 自動で用意される候補 |
| --- | --- |
| `サンプル商事株式会社` | `サンプル商事` |
| `山田 太郎` | `山田太郎` / `山田　太郎` / `山田` / `太郎` |
| `100-0001` | `1000001` / `１００－０００１` / `100` / `0001` |
| `03-1234-5678` | `0312345678` / 全角 / `03` / `1234` / `5678` |
| `東京都千代田区千代田1-1 サンプルビル 3F` | 全角 / `東京都` / `千代田区` / `千代田1-1 サンプルビル 3F` |
| `1990/01/31` | `1990-01-31` / `1990年1月31日` / `19900131` / `1990` / `1` / `01` / `31` |
| `1234 5678 9012 3456` | スペースなし / 4 桁 × 4 |

## プライバシー

**登録した値は Mac の外に出ません。** 後付けの配慮ではなく、設計の前提です。

| モデルに送るもの | 送らないもの |
| --- | --- |
| 項目の**名前**と表記（例:「会社名フリガナ（法人格を除いた表記）」） | 登録した値そのもの（氏名、住所、カード番号など） |
| 入力欄のラベル、プレースホルダ、周辺の文字、並び順 | その欄にいま入力されている内容 |
| アプリ名、ウインドウ名、ページのドメインとタイトル | ページの中身、スクリーンショット |

- 値も API キーも macOS の Keychain に保存します。
- 「送信内容に登録値が混ざっていないこと」をセルフテストで検証しています（`ProtocolTests.swift`）。
- 貼り付けに使うクリップボードには「機密」の印を付け、クリップボード履歴アプリに記録させません。元の中身は復元します。
- カード番号とセキュリティコードは画面上で伏せて表示します。
- パスワード欄では動作しません。

## はじめかた

macOS 14 以降。Xcode は**不要**で、Command Line Tools だけでビルドできます。

```bash
git clone https://github.com/lenyanagisawa/formfillai.git
cd formfillai/macos
./scripts/build-app.sh
open build/FormFillAI.app
```

1. **アクセシビリティ**の許可を求められたら許可します（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。
2. メニューバーのアイコン → **登録情報と設定…** → **設定** タブで、Jev への接続方法を選んでキーを入れます。
3. **登録情報** タブで、使いそうな欄だけ埋めます。入力は自動保存、空欄は登録されません。
4. 好きな入力欄にカーソルを置いて `⌥ Space`。

> **コード署名について。** macOS はアクセシビリティの許可を、アプリの署名と紐づけて覚えます。アドホック署名のままだと、
> ビルドし直すたびに許可が外れます。キーチェーンアクセス → 証明書アシスタント → 証明書を作成… で、
> 名前 `FormFillAI Local Signing`・種類「コード署名」の自己署名証明書を作り、信頼設定の「コード署名」を「常に信頼」にしてください。
> `build-app.sh` が自動で使います。別の名前にしたい場合は `CODESIGN_IDENTITY="…"` で指定できます。

### Jev への接続方法

問い合わせの内容はアプリの中で組み立てるので、どの経路でも結果は同じです。

| 経路 | 必要なもの | 補足 |
| --- | --- | --- |
| **Vercel AI Gateway（直接）** — 既定 | [AI Gateway の API キー](https://vercel.com/docs/ai-gateway) | サーバー不要。最速（約 0.5 秒）。公式 SDK が内部で使っているエンドポイントで、公開ドキュメントには無く、変わる可能性があります。 |
| **自前の中継サーバー** | [`relay/`](relay/) を Vercel にデプロイ | API キーを端末に置かずに済み、チームで共有できます。0.3 秒ほど遅くなります。 |
| **TypeSafe AI（直接）** | TypeSafe の API キー | 公開情報をもとに実装しており、**実際の疎通は未確認**です。 |

AI Gateway は無料クレジットを使う場合でもカードの登録が必要で、無料枠にはレート制限があります。
Jev の料金は入力 100 万トークンあたり約 $0.04、1 回の入力は 2,000〜3,000 トークン程度です。

<details>
<summary>中継サーバーのデプロイ手順</summary>

```bash
cd relay
npm install
npx vercel link
npx vercel env add AI_GATEWAY_API_KEY production
npx vercel env add FORMFILLAI_API_TOKEN production   # 十分に長いランダム文字列
npx vercel deploy --prod
```

設定で「自前の中継サーバー」を選び、`https://<your-app>.vercel.app/api/evaluate` とトークンを入れます。
中継サーバーは指示文を持たず、リクエストの中身も記録しません。問い合わせを渡すだけです。
</details>

## 精度

115 ケース・候補 約 105 個（`eval/`）、「常に自動入力」モードでの実測:

- **1 発で正解: 約 95〜97%**。残りは **違う** を 1 回押して直します。
- 外れの多くは項目の取り違えではなく、表記の取り違え（全角か通常か、`MM/YY` か `MM/YYYY` か）です。

```bash
python3 eval/build-fixtures.py          # アプリと同じコードで問い合わせを組み立て直す
AI_GATEWAY_API_KEY=... node eval/run.mjs
```

## 制約

- ラベルが画像だけの欄や、独自実装の入力部品は、手がかりが少なく当たりにくくなります。
- 入力は**欄全体の置き換え**です（`⌘A` → `⌘V`）。違う場所で押してしまったら、その欄で `⌘Z` すれば戻ります。
- Chromium / Electron 系のアプリは、要求されてから画面の中身を公開します。FormFillAI の起動直後は最大 1.6 秒ほどかかることがあります。
- 日本語のフォームが主な対象です。英語フォームはローマ字氏名やカード情報には対応しています。

## 関係について

FormFillAI は独立したプロジェクトで、TypeSafe AI および Vercel とは関係ありません。「Jev」は TypeSafe AI のモデルです。
